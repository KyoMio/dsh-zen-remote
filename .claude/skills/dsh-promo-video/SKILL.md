# DSH 插件小红书推广物料

产物放在 `promo/<插件>-<版本>/`，不进任何仓库。上一版目录就是**模板**：脚本、合成页、渲染与混音工具都从那里复制，最新的是 `promo/zen-remote-2.3.2/`（说明在它的 `脚本.md`）。

## 用户的固定要求

这些是用户纠正过的偏好，每一版都照做：

- 界面素材全部是软件真实代码渲染的截图，在隔离 DSH 实例上按真实流程操作出来；后期只叠加说明元素（大字、标注框、光标、代码卡片）。
- 截图套设备外框，标注框按截图时实测的元素坐标画，贴合被圈元素。
- 文案用规范说法和项目术语（主服务端 / 子客户端），不口语化。
- 涉及服务端、设置的镜头突出安全，写清代价。
- 每版配乐重新做（原创合成），风格与画面一致。
- 视角跟随用户真实使用方式：一镜只在一台设备上操作，用标注说明它实际运行在哪。

## 步骤

### 1. 定主打

- `mem0_search` 搜「promo video / 宣传片」找上一版的偏好与教训；读上一版的 `脚本.md`、`小红书笔记.md`。
- 读新版本的改动：插件仓 `git log <上一版 tag>..<新 tag>`、README、`docs/`、本地 `tasks/` 的验收清单、界面文案（`src/client/locales.ts` 一类）。
- 主打由用户定。用户已说明主打时直接用；没说时列出候选一句话问。

完成标志：确定 1 个主打，脚本里每句功能描述都能对应到 README / docs 的某处原文。

### 2. 写脚本，等用户确认

写 `promo/<新目录>/脚本.md`：分镜表（时间 | 画面 | 大字 | 标注）、配乐方案（BPM、调式、和弦、段落与镜头对齐）、素材拍摄方法、需要用户决定的问题。全片约 36 秒，镜头切换落在小节线上（一小节 = 240/BPM 秒）。

在对话里贴出分镜表，等用户确认后再动手；用户提的修改回写到 `脚本.md` 并标注第几稿。

完成标志：用户明确同意开拍。

### 3. 拍素材

按 [references/capture.md](references/capture.md) 起两套隔离实例、写演示数据、逐镜截图并记录坐标。

每个要在片中声称的功能，先在隔离实例里真实操作一遍。功能不工作时停下，用 `ask_user_question` 让用户选：先修插件再拍 / 删掉这一镜 / 其他；同时把 bug 记进插件的本地 `tasks/` 待办。画面上补出来的「能用」不算。

完成标志：分镜里每张截图都已落盘到 `captures/`，坐标写进 `captures/boxes*.json`；演示网关已改回只监听 `127.0.0.1`，隔离实例已全部停止（`lsof` 查端口为空）。

### 4. 合成、配乐、出片

按 [references/compose.md](references/compose.md) 改 `video.html`、重做 `audio/make_bgm.py`、渲染并混音。

完成标志：`check-layout.mjs` 输出 `no issues`；`ffprobe` 显示 1080×1920、30 帧、36 秒、H.264 + AAC；ebur128 测得 −16 LUFS 左右、真峰值不高于 −1.3 dBFS；`out/storyboard.png` 已生成，并逐张看过关键帧（缩小后再交给看图工具，大图会超时）。

### 5. 交付视频

在回复里给成片路径和分镜总览，说明画面内容、真实性（哪些是真操作、哪些是写入的演示数据、没调用模型）、配乐参数，以及拍摄中发现的插件问题。说明配乐只做了客观检查，听感要用户自己确认。

### 6. 封面与笔记

用户要求时再做（可能与视频同一轮，也可能分开）。做法见 [references/compose.md](references/compose.md) 的「封面」「笔记」两节。用户要正文时，把正文以代码块直接贴在回复里，方便复制。

完成标志：`out/cover-3x4.png` 已渲染并看过；`小红书笔记.md` 有 3 个标题候选（≤20 字）、正文、评论区置顶、发布前确认。

### 7. 收尾

- `脚本.md` 末尾补「成片与重新出片」：产物、文件作用表、重新出片命令、实例怎么重起。
- 工作区 `AGENTS.md` 目录表的 `promo/` 一行补上新目录。
- 本轮踩的新坑写进 [references/capture.md](references/capture.md) 或 [references/compose.md](references/compose.md) 的对应小节（这份 skill 就是教训的唯一存放处），跨项目的教训另用 `mem0_add` 存。
